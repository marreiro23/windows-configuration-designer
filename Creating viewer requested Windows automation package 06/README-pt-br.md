# Windows Configuration Designer: Criando pacote de automação do Windows solicitado pelo visualizador 06

**Nota:** Este é um pacote de automação personalizado solicitado por um visualizador. Para detalhes técnicos completos, consulte o arquivo README.md em inglês nesta pasta.

## Resumo

Este pacote automatiza a configuração do Windows, incluindo:
- Pular OOBE (Out-Of-Box Experience)
- Criar usuário administrador
- Instalar software via Chocolatey
- Configurar definições do sistema
- Personalizar área de trabalho e barra de tarefas

## Execução

Consulte o arquivo README.md (em inglês) para instruções detalhadas de execução e configuração.
